## 2. Collection Protocol — दोन-Yama Handover (नवीन)

### 2.1 मूलभूत रचना

प्रत्येक विश्वाचा **स्वतःचा यम** असतो. Universe B चा विधाता दुसऱ्या विश्वातून आत्मा **चोरत नाही** — तो त्या विश्वाच्या यमाकडे **अधिकृत विनंती** करतो.

```
[ UNIVERSE B · VIDHATA ]
   target profile तयार करतो
            │
            ▼  (1) आत्म-निर्गम विनंती (Ātma-Nirgama Patra)

   (2) नियती-पूर्णता तपासणी → (3) Release Seal + खातेवही उतारा
            │
            ▼  (4) custody transfer — विधाता ताब्यात घेतो
[ KSHIRA CORRIDOR · DVĀRA ]
   (5) gate वाचन → band
            │
            ▼ direct teleport
[ PRATIGRAHA · BUFFER ZONE · YAMA (B) ]
   (6) intake → पडताळणी → परवानगी → बंधन
```

### 6.3 Gate नियम

1. **Band = छत, भेट नाही.** Gate capacity + affinity देते; तंत्र/अस्त्र/अधिकार प्रशिक्षणानेच.
2. **Route B cha no-cheat केनन वाचते** — जे आधीच कमावले नाही ते gate देत नाही.
3. **Yama वरचा नाही** — विलयन हुकूम झाला तर gate चालत नाही.
4. **Immutable** — बदल फक्त Corrective Entry (विधाता अर्ज + यम मंजुरी).
5. **Re-reading** फक्त: प्राण-सूत्र तुटणे · प्रचंड कर्म-बदल · Trinity हस्तक्षेप.

### 6.4 Summoning — अपवाद जो नियम मोडतो

- Summoning magic **मूळ यमाला विचारत नाही** — आत्मा नियती पूर्ण होण्याआधीच ओढला जातो.
- म्हणून: **Release Seal नाही → फाईल unindexed → Pratigraha मध्ये Red-Ink.**
- Gate band **अस्थिर** असतो (अपूर्ण कर्म + जबरदस्तीचे ओढणे) — शक्ती चढ-उतार होते, हेच summoned नायकांचे खरे शाप/बल.
- **कायदेशीर प्रश्न:** summoning बेकायदेशीर आहे (मूळ विश्वाच्या यमाच्या अधिकाराचे उल्लंघन) → Gap G8.
