## 1. The Two Distinct Arrival Routes (दोन वेगळे आगमन मार्ग) [CANON]

Universe B मध्ये आत्म्याचे आगमन दोन काटेकोरपणे वेगळ्या यंत्रणांमधून होते:

```
                       [ SOUL ARRIVAL PIPELINES ]

   ┌──────────────────────────┴──────────────────────────┐
   ▼                                                     ▼
[ मार्ग A: अधिकृत आत्मा-स्थलांतर ]        [ मार्ग B: अनधिकृत आगमन ]
- विधाता मूळ यमाकडून Release Seal घेतो.    - Release Seal नाही.
- पात्रता व सुसंगतीने मूल्यांकन.            - मुख्य कारण: summoning magic.
- चित्रगुप्त Soul ID तयार करतो.             - दुर्मिळ अपवाद: void drift.
- अनंत अभिलेखाचे पुनर्विलोकन व मंजुरी.      - अनंत फक्त घडलेल्या बदलांची नोंद करतो.
```

**दोन्ही मार्गांना लागू:** आत्मा क्षीर सागराच्या **Core** मध्ये प्रवेश करत नाही (प्रवेश = विलय). तो फक्त **Soul Corridor** मधून जातो, **Dvāra Gate** वर वाचला जातो आणि **Pratigraha** गोदामात direct teleport होतो.

## 2. Route A: Official Soul Migration Workflow (अधिकृत आत्मा-स्थलांतर कार्यप्रवाह)

1. **मूळ यमाकडे विनंती:** Universe B चा विधाता `Ātma-Nirgama Patra` ने विशिष्ट आत्मा मागतो.
2. **Purṇa-Karma तपासणी:** मूळ यम तपासतो — नियतीचे सर्व Key Turns पूर्ण? कर्म शिल्लक? प्रतिज्ञा प्रलंबित? (CS-1…CS-6)
3. **Release Seal:** तपासणी पास झाल्यावरच मूळ यम आत्मा सोडतो; विधाता custody घेतो.
4. **मूल्यांकन निकष (हे कधीही एकत्र करू नयेत):**
   - **स्थलांतर पात्रता:** आत्मा Universe B मध्ये प्रवेश करण्यास पात्र आहे का.
   - **वैश्विक सुसंगती (५ घटक):**
     1. *आचरण:* भूतकाळातील कृत्ये आणि परिणाम.
     2. *इच्छा व आसक्ती:* हेतू आणि मानसिक दिशा.
     3. *त्रिगुण स्थिती:* सत्त्व, रज आणि तम यांचे प्रमाणबद्ध संतुलन.
     4. *कर्म-फल:* कोणती कर्मबीजे अजून सक्रिय आहेत vs भोगली गेली.
     5. *मुक्ति-प्रश्न:* पुनर्जन्मासाठी बांधलेला आहे का किंवा मुक्तीच्या मार्गाशी संरेखित.
5. **Soul ID तयारी:** चित्रगुप्त स्वतः प्रशासकीय अभिलेख तयार करतो (कुळ, जन्मजात गुण, अभिरुची).
6. **सिस्टीम पुनर्विलोकन:** अनंत अभिलेखाचे पुनर्विलोकन करतो, मंजुरी देतो किंवा सुधारणा सुचवतो.
7. **Pratigraha official dock:** मंजूर आत्मा Release Seal सह सीलबंद Ātma-Patra मध्ये **Pratigraha** च्या scheduled official lane मध्ये येतो; सेतुव्रत फक्त receipt नोंद करतो (RIKTA marker नाही), लेख्या पडताळणी करते.
8. **कर्मबंध अवतरण:** मंजुरीनंतर विधाता त्या आत्म्याला कर्मबंधाद्वारे नेमून दिलेल्या नश्वर शरीराशी जोडतो.

## 3. Route B: Unauthorized / Unexpected Arrival (अनधिकृत आगमन)

- **मुख्य कारण — summoning magic:** आवाहकाचे circle आत्म्याला नियती पूर्ण होण्याआधीच ओढते. मूळ यमाला विचारले जात नाही → **Release Seal नाही** → फाईल अनधिकृत.
- **दुर्मिळ अपवाद — void drift:** भेग, आपत्ती किंवा प्रवाह-प्रतिध्वनीने आत्मा corridor मध्ये येतो; हाही release-seal-विरहितच.
- **प्रवास:** आत्मा **Soul Corridor** मधून जातो; **Core मध्ये प्रवेश निषिद्ध** (K2 — पूर्ण विलय).
- **Power Band:** **Dvāra Gate** karma + soul purity + gating standard वाचते आणि **तात्पुरता band** देते. Summoning मुळे band **अस्थिर** असतो — शक्ती चढ-उतार होते.
- **आगमन:** direct teleport → **Pratigraha** (Yama कार्यालयाचे मैदान, Buffer Zone). सेतुव्रता `[STATUS: RIKTA / UNINDEXED]` शिक्का मारतो; लेख्या पडताळणी करते; release seal नसल्याने **Red-Ink** उघडते.
- **तात्काळ शक्ती नाही:** band हा **छत** आहे, भेट नाही. तंत्र, अस्त्र आणि अधिकार प्रशिक्षण/दीक्षेशिवाय मिळत नाहीत. Route B चे "zero cheat" केनन अभंग.
- **सिस्टीमची भूमिका:** अनंत आगमन घडवत नाही, आत्मे निवडत नाही किंवा शक्ती देत नाही. जे बदल प्रत्यक्ष घडतात त्याची अनंत **स्वयंचलित नोंद** करतो.

## 4. Distinctions to Preserve (जपून ठेवायचे फरक) [CANON]

| संकल्पना | नेमकी केनन व्याख्या |
| :--- | :--- |
| **Ātma-Śuddhi (आत्म-शुद्धी)** | आत्म्याची स्वतःची अंतर्निहित आध्यात्मिक शुद्धता — **मलिन · शुद्ध · निर्मल · विमल**. |
| **सूक्ष्म कर्म** | अस्तित्वभर वाहून नेलेला सूक्ष्म कार्मिक संवेग. |
| **आत्म-भाग्य** | कर्म-प्रभावित नशीब, विशेषतः जन्माचे कुटुंब/कुळ याबाबत. |
| **Soul ID** | चित्रगुप्ताने तयार केलेला अधिकृत प्रशासकीय अभिलेख. |
| **नियती-अभिलेख** | अनंताची उपलब्ध सिस्टीम-कोरीव (लिखित vs रिक्त). |

| **Dvāra Gate** | Soul Corridor मधील स्वयंचलित वाचन-द्वार; band ठरवते, न्याय करत नाही. |
| **Pratigraha** | Yama कार्यालयाच्या मैदानातील आगमन-गोदाम; सेतुव्रता वॉर्डन (प्रस्तावित नाव). |
| **Release Seal** | मूळ विश्वाच्या यमाची परवानगी; त्याशिवाय आत्मा हलत नाही. |
