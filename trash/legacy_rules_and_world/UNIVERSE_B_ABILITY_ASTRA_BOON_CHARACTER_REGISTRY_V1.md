======================================================================
0. HOW TO USE THIS FILE
======================================================================

This is the next operational layer after the Power System Bible. It provides:
1. One consistent template for every ability.
2. One specialised template for astras/weapons.
3. One specialised template for boons/curses.
4. One character power-profile template.
5. A starter registry of source-inspired cases already present in the research catalogue.
6. A review checklist to catch contradictions before a power enters the novel.

Status labels:
[ESTABLISHED CANON] Author-established fact.
[SOURCE CONTEXT] A source-specific narrative or concept; check the named text/edition before publication-grade claims.
[PROPOSAL] Optional Universe B adaptation, not yet approved.
[OPEN] Unresolved.
[DO NOT GENERALISE] Do not turn this case into a universal rule.

IMPORTANT:
A source-inspired ability is not automatically a Universe B ability. The source may portray a special event, a divine act, a philosophical claim, a narrative boon, or a specific epic weapon. The registry must preserve that difference.

6. POWER SYSTEM QA CHECKLIST
======================================================================

Before adding any ability to the novel, answer:

[ ] Does it belong to one or more of the six pillars for a clear reason?
[ ] Is the ability itself being mistaken for a seventh pillar?
[ ] Is the source claim separated from the fictional adaptation?
[ ] Are access, knowledge, activation, control, and outcome separated?
[ ] Does it have scope and limits?
[ ] Does it have at least one meaningful counter or constraint?
[ ] Does it conflict with an established character, deity, office, or event?
[ ] Does it accidentally change Universe A?
[ ] Does it make Ananta conscious, omniscient, or a power-granter?
[ ] Does it break Soul Administration or confuse Migration Eligibility with Compatibility?
[ ] Does it expose Atma-tattva prematurely?
[ ] Does it make Karma a morality score?
[ ] Does it make Energy a universal explanation for every phenomenon?
[ ] Does it imply all Asuras are evil or all Devas are good?
[ ] Can a clever reader exploit the rule in a way the author did not intend?
[ ] Has the author explicitly approved it?

If any critical item fails, mark the entry [REVISE] or [PARK], not [CANON].

======================================================================
7. WHAT TO BUILD NEXT
======================================================================

Recommended order:
1. Approve/revise the Power System Bible mechanics.
2. Define the protagonist's profile using Section 4.
3. Define 3–5 major characters and one antagonist with the same profile.
4. Create a small initial ability list for those characters—not hundreds of abilities.
5. Give each important Astra and Boon its own record.
6. Run matchup tests: protagonist vs rival, protagonist vs a superior Authority, and protagonist vs a conditional Boon.
7. Check story progression and mystery reveals against the rules.
8. Only then build a larger ability encyclopaedia.

Reason:
A giant ability catalogue before the protagonist, antagonist, and story conflicts are defined creates unnecessary complexity. The power system should serve character choices and plot pressure, not become a disconnected wiki.
